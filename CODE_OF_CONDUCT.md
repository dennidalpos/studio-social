# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome different viewpoints, accept constructive feedback gracefully, and keep discussion focused on the work. Harassment, discrimination and personal attacks are not accepted.

Report unacceptable behavior privately through GitHub's private vulnerability reporting on this repository (Security tab) or by contacting the maintainer through their GitHub profile. Maintainers may edit, reject or remove contributions that violate this code.
