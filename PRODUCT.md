# Product

## Register

product

## Users

One person managing their own social presence: freelancers, small studios and professionals. Two situations: a personal login only (no API access) or a business profile / Page with API access. Used on a laptop and, for the simple view, on a phone.

## Product purpose

Studio Social turns a brief into editable social posts and helps publish them. The simple view (default) writes, previews and copies the text, then opens the social in the user's own browser so they press Publish themselves. The advanced view adds an editorial plan, scheduling and API publishing for LinkedIn, Facebook and Instagram, and export for TikTok. Success: a post is ready and published in a few minutes, with no surprise sends.

## Brand personality

Calm, editorial, trustworthy. Plain language, no hype. Warm green palette with serif display type (Instrument Serif) and DM Sans for text.

## Anti-references

Dashboards crowded with metrics, growth-hacking tone, dark patterns that push automatic posting, and anything that automates or reads personal logins. The optional separate browser window only keeps the user's own cookies in a local, Git-ignored profile; the app never sees or fills credentials.

## Design principles

1. Simple first: the default view needs no account, key or setup.
2. The user stays in control: publishing with personal logins is always their own action.
3. Honest state: demo mode and live mode are always visibly distinct.
4. Phone-ready: 44px targets, no horizontal scroll at 375px.
5. Readable and accessible: strong contrast in light and dark, visible focus, clear labels.

## Accessibility and inclusion

Target WCAG 2.2 AA. Respect `prefers-color-scheme` and reduced motion. The UI is available in Italian and English (selector in the top bar); docs are English.
